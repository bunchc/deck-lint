# Observability Rules

This section has rules to make sure all Kong parts can be tracked with logs, metrics, and traces.

## Rules

| Rule File                                                                                    | Name                                                                                                       | Description                                                                            |
| -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| [`disallow-file-log-in-production.yaml`](./disallow-file-log-in-production.yaml)             | `disallow-file-log-in-production`                                                                          | Avoids using the `file-log` plugin in production to support central logging.           |
| [`enforce-global-observability-plugins.yaml`](./enforce-global-observability-plugins.yaml)   | `enforce-global-prometheus-plugin`, `enforce-global-opentelemetry-plugin`, `enforce-global-logging-plugin` | Checks that Prometheus, OpenTelemetry, and logging plugins are used everywhere.        |
| [`enforce-opentelemetry-config.yaml`](./enforce-opentelemetry-config.yaml)                   | `enforce-opentelemetry-config`                                                                             | Checks if the OpenTelemetry plugin sends traces to the right place at the right speed. |
| [`enforce-secure-opentelemetry-exporter.yaml`](./enforce-secure-opentelemetry-exporter.yaml) | `enforce-secure-opentelemetry-exporter`                                                                    | Makes sure the OpenTelemetry plugin uses a secure (HTTPS) endpoint.                    |
| [`enforce-w3c-trace-context.yaml`](./enforce-w3c-trace-context.yaml)                         | `enforce-w3c-trace-context`                                                                                | Requires using W3C Trace Context for tracing in the OpenTelemetry plugin.              |
| [`mandate-correlation-id-plugin.yaml`](./mandate-correlation-id-plugin.yaml)                 | `mandate-correlation-id-plugin`                                                                            | Makes sure the 'correlation-id' plugin is on everywhere for tracing and fixing issues. |
| [`recommend-slo-monitoring-tags.yaml`](./recommend-slo-monitoring-tags.yaml)                 | `recommend-slo-monitoring-tags`                                                                            | Suggests adding SLO tags to services and routes to help with SLO tracking.             |
| [`require-log-sanitization.yaml`](./require-log-sanitization.yaml)                           | `require-log-sanitization`                                                                                 | Suggests setting up log cleaning to stop private data from leaking.                    |
| [`require-logging-plugin.yaml`](./require-logging-plugin.yaml)                               | `require-logging-plugin`                                                                                   | Makes sure every service has a logging plugin for central logging.                     |
| [`require-prometheus-plugin.yaml`](./require-prometheus-plugin.yaml)                         | `require-prometheus-plugin`                                                                                | Makes sure the Prometheus plugin is on to provide metrics for tracking.                |
